## 排版一览

X-Reader 使用阅读优先的排版：合适的行高、克制的颜色，以及一个可以自由调整的版心。你可以从右上角的 **阅读设置** 里切换浅色 / 深色主题、衬线 / 无衬线字体和字号。

**重点文字**、*斜体* 和 `行内代码` 都会按 Markdown 规则渲染。列表也是：

1. 打开一个或多个 `.txt` / `.md` 文件
2. 用标签页在文档之间切换
3. 文件在外部被修改时，阅读视图会自动更新

- 支持拖入窗口打开
- 关闭标签页不会改动文件
- 阅读位置会被记住

### 小节标题

段落之间保持舒适的间距。中文与 English mixed 排版时，字体会自动回退到合适的字体。

## 代码与表格

```ts
interface Document {
  path: string;
  encoding: string;
  readOnly: true;
}
```

| 能力 | 说明 |
| --- | --- |
| 多标签 | 同时阅读多份文档 |
| 自动刷新 | 监听文件变化，约 200ms 防抖 |
| 编码识别 | UTF-8 / GBK / Big5 / UTF-16 等 |
| 只读 | 不提供任何写入入口 |

## 自动刷新

用编辑器保存本文件，或者运行下面的命令，阅读视图会自动更新，无需手动刷新：

```powershell
Add-Content -Path "欢迎使用.md" -Value "`n新增的一行会立即出现。"
```

窗口底部状态栏的绿点表示自动刷新正在工作。若文件被删除或移动，标签页会给出提示，并保留最后一次读取的内容。

### 关于只读

X-Reader 没有任何保存、改写或格式化文件的命令。它打开文件，只为了阅读。
